# component_import

Python-часть системы «КОМПОНЕНТ» — управление библиотеками электронных
компонентов, закупками и запасами для САПР **KiCad** с выпуском документации
по ЕСКД (eskd-templates) и складским ядром **Part-DB**.

Пакет закрывает этапы 0–4 плана: мастер импорта унаследованных PCAD-библиотек
с автоматическим нормоконтролем, двойное УГО (ГОСТ/IEC), импорт прайс-листов
и калькуляцию стоимости изделия по схеме.

## Установка

```bash
pip install -e .        # Python >= 3.10; ставит 4 CLI-утилиты
python -m pytest tests/ # 16 «золотых» тестов = приёмочные испытания ПИ-1…ПИ-6
```

## Утилиты

| CLI | Назначение |
|---|---|
| `component-import` | импорт библиотеки: валидаторы В-1…В-7/В-9, слияние приёмки «5», автоисправления (кодировка, дюймы→мм, санация имён), 3D-заглушки, отчёт, выгрузка в Part-DB |
| `component-project` | двойное УГО: сборка представлений -GOST/-IEC, переключение проекта без смены позиционных обозначений, аудит статусов (FR-7) |
| `component-price` | прайс-листы: конвертеры поставщиков → внутренний формат, память соответствий, устаревание цен |
| `component-cost` | стоимость изделия по .kicad_sch/BOM: склад/закупка, MOQ, ценовые пороги, приёмка, версии калькуляций |

Быстрый старт на эталонных данных:

```bash
component-import tests/golden_k50 -o out --lib-name K50-35 \
    --field-map config/field_map_pcad.csv --tu config/tu_OZh0464214.yaml --dry-run
```

## Состав репозитория

- `component_import/` — пакет (парсер s-expression KiCad, правила
  нормоконтроля, конвейер импорта, прайсы, калькуляция, клиент Part-DB API);
- `tests/` — золотые тесты с эталонной серией К50-35 (130 символов → 65
  деталей, известные количества дефектов каждого класса);
- `config/` — контракт полей eskd-templates, маппинг PCAD-полей, эталон
  ТУ ОЖ0.464.214, подключение KiCad (HTTP library);
- `converters/` — конвертеры прайсов (образец: ~30 строк на поставщика);
- `stage0_kit_v1.1/` — комплект развёртывания стенда (Part-DB + PostgreSQL +
  Gitea, бэкапы, обновление);
- `ОТЧЁТ_*.md`, `План_реализации_КОМПОНЕНТ.md` — проектная документация.

## Смежное

Серверная сторона — [Part-DB](https://github.com/Part-DB/Part-DB-server)
(KiCad HTTP library, склад, поставщики); ТЗ на его доработки (приёмка,
статусы, два УГО-представления) — в проектной документации.
Документация ЕСКД — [eskd-templates](https://github.com/baranovskiykonstantin/eskd-templates).
